# v0.5.1

- macOS 后台凭据读取在调用系统钥匙串前禁止认证 UI。锁定、拒绝授权、程序更新后的 ACL 不匹配不再导致 MCP 启动反复弹窗。
- 凭据不可用时 MCP 仍可握手，`server_info` 报告明确状态，生图错误提供恢复操作；已有环境变量和可无交互读取的 Key 继续可用。
- 新增 `credentials authorize` 与隐藏输入的 `credentials set`，不重写客户端配置。授权取消立即失败，只有后续无交互读取验证通过才报告成功。
- 保留现有 Keychain service/account、User domain、五个 MCP 工具及动态模型目录。Linux/Windows 的凭据后端语义保持不变。
