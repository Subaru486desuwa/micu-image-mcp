# v0.7.0

## 升级方式

已安装的 MCP 不会自动更新，请重新运行安装命令。已保存的 API key 不用重新输入，macOS 可能重新询问一次钥匙串授权。

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/Subaru486desuwa/micu-image-mcp/main/scripts/install.sh | sh
```

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/Subaru486desuwa/micu-image-mcp/main/scripts/install.ps1 | iex
```

完成后重新连接 MCP，调用 `server_info` 确认 `version` 为 `0.7.0`。Claude Desktop 普通 Chat 模式不由安装器配置，请按[兼容性指南](https://github.com/Subaru486desuwa/micu-image-mcp/blob/main/docs/claude-desktop-compatibility.md)更新。

## 新增 Seedream 文生图

- 新增模型 `doubao-seedream-5-5-261028`，只用于 `image_generate`，需要在调用时传 `model`。默认模型不变。请先确认当前凭据开通了该模型。
- 默认不带水印。上游默认会在右下角加「AI生成」标识，MCP 的请求固定关闭它；对外发布图片时，标识义务由使用方承担。
- 尺寸：总像素须在 921,600 到 4,624,220 之间，例如 1280×720、2048×2048、2560×1440。最高约 2K，不支持 4K；超出范围在请求前拒绝，不计费。
- `output_format` 只接受 `png` 和 `jpeg`。Seedream 没有 `quality` 参数，传入会被忽略，并在 `notes` 中说明。
- 任意尺寸下 `n>1` 最多 5 个请求并发。gpt-image 在 2K/4K 上的 `n=1` 限制和串行排队不适用于 Seedream。
- 不支持编辑。上游的编辑接口对 Seedream 返回成功，但会忽略输入图、按提示词另画一张并照常计费，所以 `image_edit`、`image_batch_edit`、`image_multi_reference` 在请求前拒绝该模型。
- Seedream 可以用 `session_id="new"` 开始会话。之后编辑这个会话时，必须显式传入可编辑的 `model`（如 `gpt-image-2.6-sunburst`）；不传会被拒绝，不会自动换模型。

## 默认可信下载域名增加 `volces.com`

Seedream 的结果放在火山引擎对象存储上。`MICU_TRUSTED_DOWNLOAD_HOSTS` 的默认值改为 `oss.filenest.top,volces.com`，使用 Clash / Surge fake-ip 时这两个域名的图片可以正常下载。

自行设置过这个变量的用户不受默认值影响：要用 Seedream，请把 `volces.com` 加进去，否则图片已计费却无法保存。

## 会话续作失败时的结果更完整

`image_generate` 在已有会话上续作时，若上游请求或保存失败，结果现在与普通 `image_generate` 的失败一致地包含 `saved`（空列表）、`errors`、`requested_n`、`size_honored`。原有的 `error` 与 `session` 字段保持不变。

## 内部重构

生成、编辑和多图参考原先各有一份「请求上游并保存图片」的逻辑，现在合并为一处；批量编辑和会话续作不再解析另一个工具的 JSON 输出。除上一节的变化外，gpt-image 各工具的输出逐字节不变，由 39 条对完整 JSON 文本的对照测试保证。

## 依赖安全更新

`rmcp` 升级到 3.10.0，`quinn-proto` 升级到 0.11.19，`quinn-udp` 升级到 0.5.16，对应 RUSTSEC-2026-0457、0461、0462、0523、0524、0538。这些公告涉及 Streamable HTTP 传输、OAuth 客户端和 QUIC；本服务器只用 stdio 传输，升级是为了让锁定的依赖不再带已知公告。

## 验收范围

2026-11-16 在米醋主站用 Seedream 完成真实调用：1024×1024、1536×1024（两张并发、JPEG）、2048×2048（两张并发、JPEG）均按请求尺寸返回，关闭水印后图片上没有标识。3840×2160 和 1024×640 被上游以像素范围拒绝，本地校验的上下限取自这两次报错。

未覆盖：`webp`、参考图输入、其他 Seedream 版本。本次验收没有用 gpt-image 模型发起真实调用，它们的行为由离线对照测试覆盖。

正式资产平台保持 Linux x86_64、macOS arm64/x86_64、Windows x86_64；离线验收已在 Linux x86_64 通过，其余平台由 Release 工作流在原生 runner 构建、测试和 smoke。本版本没有新增依赖包，锁文件只改动上一节的三个版本。
