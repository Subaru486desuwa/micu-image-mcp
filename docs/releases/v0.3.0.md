# micu-image-mcp v0.3.0 — Rust Native Default

建议所有用户升级到 v0.3.0。`main` 和推荐安装入口现已切换为安全、低内存、跨平台的 Rust
原生 MCP server；最终运行时不依赖 Python、pip、httpx 或 Pillow。

## 主要变化

- 单一原生可执行文件，默认 STDIO serve；提供 `install/reset/doctor/version`。
- 保留 5 个原 MCP tools、完整 schema、中文错误语义、路由、retry、并发和落盘结构。
- 当前协议与 2024-11-05 lifecycle 均通过黑盒验证。
- `AppPaths`/capability filesystem 统一处理 save/input/config/lock/binary 路径。
- 修复 issue #4 Windows TOML 反斜杠转义；配置经过 AST serialize + parser round-trip 后才原子替换。
- binary 安装到稳定的 per-user data-local 目录，不再依赖仓库或 `target/release`。
- API key 不写入 Codex/Claude 配置；macOS 可直接读取 Keychain。
- Python v0.2.0 reference 永久保留在
  [`python-reference`](https://github.com/Subaru486desuwa/micu-image-mcp/tree/python-reference) 分支。

## 升级

1. 从本 Release 下载对应平台文件和 `SHA256SUMS`。
2. 校验 SHA-256；macOS/Linux 给文件增加执行权限。
3. 运行：

```bash
chmod +x ./micu-image-mcp                    # macOS/Linux
MICU_SAVE_DIR="$HOME/Pictures/micu-out" \
  ./micu-image-mcp install --yes
./micu-image-mcp doctor
```

Windows PowerShell：

```powershell
$env:MICU_SAVE_DIR = "$HOME\Pictures\micu-out"
.\micu-image-mcp-windows-x86_64.exe install --yes
.\micu-image-mcp-windows-x86_64.exe doctor
```

安装器会备份现有配置，只更新 `micu-image`，保留其他 Codex/Claude 字段和 MCP server。重启
客户端后调用 `server_info`，确认 `version=0.3.0`、模型、save root 与 `api_key_configured`。

## Python 回滚

需要旧实现时，可恢复安装器生成的配置备份，或使用 `python-reference` 分支：

```bash
git clone --branch python-reference --depth 1 \
  https://github.com/Subaru486desuwa/micu-image-mcp.git micu-image-mcp-python
```

本次发布不重新启用 Grok；公开模型仍只有 `gpt-image-2` 与 `gpt-image-2-openai`。
