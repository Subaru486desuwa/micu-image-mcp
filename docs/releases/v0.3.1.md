# micu-image-mcp v0.3.1 — GPT Image 2.5

v0.3.1 updates the Rust MCP server for the current GPT Image 2.5 routes while keeping the two GPT Image 2 routes available for compatibility.

## Highlights

- Adds `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst`.
- Uses Flare by default for generation and Sunburst by default for edit, batch edit, and multi-reference workflows.
- Adds `quality` to all four image tools. GPT Image 2.5 accepts `auto`, `low`, `medium`, `high`, `xhigh`, and `max`; older models remain limited to `high` and below.
- Keeps the selected GPT Image 2.5 model for 2K/4K requests. Legacy `gpt-image-2` still routes high-resolution work to `gpt-image-2-openai`.
- Moves the maintained tool and `server_info` contracts to Rust-owned fixtures. The Python reference remains frozen.
- Removes the version number from the repository banner so future releases do not require artwork edits.

## Validation

- Rust formatting, Clippy with warnings denied, all-target tests, and STDIO smoke passed.
- Live Rust MCP calls passed for Flare/Sunburst generation and editing plus Sunburst batch and multi-reference workflows with `quality=max`.
- Flare and Sunburst both returned exact 2048×1152 and 3840×2160 output in the live size probes.

## Assets

This release publishes only the four Rust binaries and `SHA256SUMS`.
