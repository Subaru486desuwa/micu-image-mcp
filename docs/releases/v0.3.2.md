# micu-image-mcp v0.3.2 — One-line Install & Security Maintenance

v0.3.2 makes the Rust MCP easier to install from a fresh machine and refreshes the release dependencies after a newly published RustSec advisory.

## Highlights

- Adds a one-line macOS/Linux installer: `curl .../scripts/install.sh | sh`.
- Adds a one-line Windows PowerShell installer: `irm .../scripts/install.ps1 | iex`.
- Both bootstrap installers download the latest platform Rust binary and verify it against the release `SHA256SUMS` before invoking the built-in installer.
- Keeps API keys out of generated Codex/Claude configuration and retains the existing stable per-user binary install path.
- Makes the Python rollback installer PEP 668-safe by using an isolated environment where required, including Windows restart handling and rollback validation.
- Streamlines the README around installation, configuration, and runtime behavior; detailed benchmark and stress-test results remain under `docs/` and CI.
- Adds the repository Star History chart to the README.

## Security

- Updates `rustls` from 0.23.43 to 0.23.45, addressing `RUSTSEC-2026-0285` / `GHSA-2mjx-qc3c-rqvc`.

## Validation

- Full Rust tests, Clippy with warnings denied, Python compatibility tests, frozen parameter matrix, STDIO differential contracts, and Cargo audit pass.
- Native release builds pass on Linux x86_64, macOS arm64/x86_64, and Windows x86_64.
- Windows CI parses the PowerShell bootstrap installer successfully.
- The published POSIX bootstrap path was exercised in an isolated macOS home: release download, SHA-256 verification, stable binary installation, and `version` all succeeded.

## Assets

This release publishes only the four Rust binaries and `SHA256SUMS`.
